# PulseClip Wix Landing Page

Short JITRA-inspired PulseClip prelaunch page using supplied local product imagery and the approved `融合版v2｜调研卖点融合` copy direction.

## Preview

Run a local static server in this folder and open the displayed localhost URL.

## Content boundaries

- The hero uses the selected `全球首款让心率开口指导你的开放式 AI 耳夹` direction and its English rendering.
- The research section summarizes category-wide fitness-audio themes. It does not present AirPods reviews as PulseClip customer testimonials.
- Unconfirmed numerical accuracy, IP ratings, Bluetooth broadcast support, and medical claims are excluded.
- Customer-facing copy retains `data-copy-key` attributes for later review.

## Wix

Follow `WIX-SETUP.md` to connect the visible email fields to Wix Forms and automatically upsert submissions into Wix Contacts.
